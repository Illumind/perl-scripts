# Tapsum — облік NFC-оплат для Samsung (OneUI 9)

<img src="docs/logo.svg" width="96" alt="Tapsum">

Android-додаток, який автоматично записує покупки, оплачені телефоном або
Galaxy Watch через NFC, і рахує суми за день / тиждень / місяць.

## Як це працює

Android не дає стороннім додаткам бачити дані безконтактної оплати напряму —
їх бачить лише гаманець (Samsung Wallet / Google Wallet). Тому додаток читає
**сповіщення**, які гаманець або банк показує одразу після оплати, і витягує з
них суму, валюту та магазин.

Джерела за замовчуванням: Samsung Wallet, Google Wallet, monobank, Приват24,
izibank, A-Bank, Raiffeisen, ПУМБ, Ощадбанк, Sense Bank, OTP, UKRSIBBANK,
Правекс, Revolut, Wise. У меню можна ввімкнути «Читати всі додатки».

Розпізнаються формати на кшталт `Оплата ₴245,50`, `−1 245.50₴`,
`Списання 89.00 UAH`, `Payment of $12.99 at Starbucks`. Поповнення, повернення,
кешбек і суми балансу ігноруються. Дублі одного сповіщення відкидаються.

Додатково:

- **NFC-мітки.** Поки додаток відкритий, піднесіть будь-яку NFC-наліпку —
  відкриється вікно нової покупки; мітку можна прив'язати до магазину.
  Мітка з URI `purchase://add?amount=45&merchant=Кава` відкриває додаток
  навіть коли він закритий (записати таку мітку можна, напр., у NFC Tools).
- Ручне додавання, редагування та видалення записів.
- Суми окремо за валютами (UAH / USD / EUR …), середній чек.
- Експорт у CSV (через «Поділитися»).
- Material You: кольори підлаштовуються під тему OneUI.

## Встановлення

1. Завантажте APK з GitHub Actions (вкладка **Actions → NFC Purchase Tracker
   APK → artifact `moi-pokupky-apk`**) або зберіть самі:
   `cd nfc-purchase-tracker && ./gradlew assembleRelease`.
2. Встановіть APK на телефон.
3. **OneUI 9 / Android 13+:** доступ до сповіщень для встановлених не з
   Galaxy Store / Play додатків заблоковано. Відкрийте
   *Налаштування → Програми → Мої покупки → ⋮ → Дозволити обмежені
   налаштування*.
4. У додатку натисніть **«Надати доступ»** і ввімкніть «Мої покупки».
5. Увімкніть сповіщення про оплату в Samsung Wallet / банківському додатку.

> Поки додаток відкритий на екрані, телефон працює як NFC-зчитувач, тож
> оплачуйте покупки при закритому додатку.

## Структура

| Файл | Призначення |
|---|---|
| `PaymentParser.kt` | розбір тексту сповіщень (чистий Kotlin, покритий тестами) |
| `PaymentNotificationListener.kt` | `NotificationListenerService`, що ловить оплати |
| `PurchaseRepository.kt` | SQLite-сховище, налаштування, CSV |
| `MainActivity.kt` | інтерфейс Compose і зчитування NFC-міток |
