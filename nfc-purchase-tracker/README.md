# Tapsum — облік витрат для Samsung (OneUI 9)

<img src="docs/logo.svg" width="96" alt="Tapsum">

**Приклав — порахував.** Tapsum автоматично записує покупки, оплачені
телефоном, Galaxy Watch або карткою, розкладає їх за категоріями, стежить за
бюджетом і показує статистику. Мови: українська, English, Polski.

Повне ТЗ: [`docs/TZ.md`](docs/TZ.md).

## Що вміє (MVP 0.2)

- **Автоматичний запис** зі сповіщень Samsung Wallet, Google Wallet і банків
  (monobank, Приват24, ПУМБ, A-Bank, izibank, Ощад, Sense, Raiffeisen, OTP,
  UKRSIBBANK, Revolut, Wise, PKO BP, mBank, ING, Santander, Pekao, Millennium).
  Розпізнається сума, валюта, магазин, картка (*1234) і тип: NFC / картка / онлайн.
  Поповнення, повернення, кешбек і баланс ігноруються.
- **Без дублів**: якщо ту саму оплату показали і гаманець, і банк, буде один запис з даними обох.
- **Категорії автоматично** за назвою магазину (АТБ → Продукти, WOG → Пальне,
  Biedronka → Продукти…). Виправили категорію — магазин запам'ятовується.
  Можна створювати свої категорії з емодзі й кольором.
- **Бюджет** на місяць і ліміти на категорії, прогноз до кінця місяця,
  сповіщення на 80 % і 100 %. Місяць може починатися з дня зарплати.
- **Статистика**: кругова діаграма, витрати по днях / місяцях, порівняння
  з минулими місяцями, топ магазинів.
- **Історія** з пошуком і фільтрами (місяць, тип оплати, категорія), редагування й видалення з «Повернути».
- **NFC-мітки**: поки додаток відкритий, піднесіть наліпку — відкриється нова покупка
  з запам'ятованим магазином. Мітка з URI `purchase://add?amount=45&merchant=Кава`
  відкриває додаток і коли він закритий.
- Експорт у CSV, темна/світла тема за системою, дані лише на телефоні.

## Встановлення

1. Завантажте APK: GitHub → **Actions → Tapsum APK** → останній
   успішний запуск → артефакт `tapsum-apk`.
2. Встановіть APK на телефон.
3. **OneUI / Android 13+**: доступ до сповіщень для додатків не з магазину
   заблоковано. *Налаштування → Програми → Tapsum → ⋮ → Дозволити обмежені налаштування*.
4. Відкрийте Tapsum і пройдіть 3 екрани привітання (доступ до сповіщень, нагадування про бюджет).
5. Переконайтесь, що сповіщення про оплати увімкнені в Samsung Wallet / банку.

> Поки Tapsum відкритий на екрані, телефон працює як NFC-зчитувач —
> оплачуйте покупки при закритому додатку.

## Розробка

```bash
./gradlew testDebugUnitTest   # тести парсера, категорій, статистики
./gradlew assembleRelease      # APK
python3 tools/gen_strings.py   # перегенерувати переклади (EN/UK/PL) з однієї таблиці
```

| Файл | Призначення |
|---|---|
| `PaymentParser.kt` | розбір сповіщень: сума, валюта, магазин, картка, тип оплати |
| `CategoryClassifier.kt` | категорія за назвою магазину |
| `Domain.kt` | моделі, розрахунки статистики та бюджетів, форматування грошей |
| `Repo.kt` | SQLite-сховище, злиття дублів, навчання категорій, налаштування |
| `Notifier.kt` | сповіщення про бюджет |
| `PaymentNotificationListener.kt` | служба, що ловить сповіщення про оплату |
| `ui/` | екрани Compose: Головна, Історія, Статистика, Бюджет, Налаштування, онбординг |
